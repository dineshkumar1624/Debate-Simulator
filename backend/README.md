# AI Debate Simulator — Backend Service

A multi-agent adversarial debate orchestration backend built with FastAPI, LangGraph `StateGraph`, Qdrant vector retrieval, Sentence Transformers, and PostgreSQL/SQLAlchemy persistence.

---

## 1. System Overview

- **Orchestration**: Genuine LangGraph cyclic `StateGraph` managing turn-by-turn evidence retrieval, bilateral rebuttals, dynamic round termination, and final judicial evaluation.
- **Model Architecture**: Standardized on EXACT THREE AI models:
  - **PRO Agent**: `Google Gemma 4 E4B Instruct` (`Q4_0` GGUF at `D:\models\gemma-4-E4B-Q4\gemma-4-E4B_q4_0-it.gguf` via persistent `llama.cpp` HTTP server at `http://127.0.0.1:8081/v1`)
  - **CON Agent**: `Alibaba Qwen2.5-VL-7B-Instruct` (Negative challenge & adversarial cross-examination at `D:\models\Qwen2.5-VL-7B-Instruct`)
  - **JUDGE Agent**: `Google Gemini 3.5 Flash` (`gemini-3.5-flash` via official `google-genai` SDK and secure API key)
- **Knowledge Retrieval**: Qdrant vector store (`debate_knowledge` collection) using 384-dimensional cosine embeddings generated by `sentence-transformers/all-MiniLM-L6-v2`.
- **Relational Persistence**: SQLite/PostgreSQL with automatic fallback for state and authoritative transcript history. Schema managed via Alembic.

## 2. Environment Configuration

Copy `.env.example` to `.env` or set environment variables:

```env
# Relational Database (SQLite default or PostgreSQL)
DATABASE_URL=sqlite:///./debate_simulator.db

# Qdrant Vector Store (Leave QDRANT_URL empty for embedded local storage)
QDRANT_URL=
QDRANT_API_KEY=
QDRANT_STORAGE_PATH=./qdrant_data
QDRANT_COLLECTION_NAME=debate_knowledge

# Sentence Transformers Embeddings (384-dimensional)
EMBEDDING_MODEL_NAME=sentence-transformers/all-MiniLM-L6-v2

# EXACT THREE STANDARDIZED MODELS
# 1. PRO AGENT — Gemma 4 E4B Q4_0 GGUF via llama.cpp
GEMMA_MODEL_PATH=D:\models\gemma-4-E4B-Q4\gemma-4-E4B_q4_0-it.gguf
GEMMA_BASE_URL=http://127.0.0.1:8081/v1
GEMMA_MODEL_NAME=gemma-4-E4B-Q4_0
GEMMA_AUTOSTART_SERVER=true
GEMMA_TIMEOUT_SECONDS=120.0
PRO_MAX_NEW_TOKENS=256

# 2. CON AGENT — Qwen 2.5 VL 7B Instruct
QWEN_MODEL_PATH=D:\models\Qwen2.5-VL-7B-Instruct
QWEN_MODEL_NAME=Qwen2.5-VL-7B-Instruct
CON_MAX_NEW_TOKENS=128

# 3. JUDGE AGENT — Google Gemini 3.5 Flash API
GEMINI_API_KEY=your_gemini_api_key_here

GEMINI_TIMEOUT_SECONDS=60.0

# Inference Device & Mode
INFERENCE_DEVICE=cpu
ENABLE_LOCAL_LLM_INFERENCE=true

SEARCH_PROVIDER=duckduckgo
```

## 3. Database Migrations

Apply database schema migrations via Alembic:

```bash
cd backend
python -m alembic upgrade head
```

To autogenerate new schema revisions:
```bash
python -m alembic revision --autogenerate -m "migration_name"
```

## 4. Running the Backend Server

Start the FastAPI ASGI server with Uvicorn:

```bash
cd backend
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Interactive OpenAPI documentation is accessible at:
- `http://localhost:8000/docs`
- `http://localhost:8000/redoc`

## 5. API Endpoints

### Document Ingestion
- `POST /api/documents/upload`: Upload PDF, Image, or Text file. Extracts text/OCR, creates bounded chunks, embeds, indexes into Qdrant, and stores in SQL.
- `GET /api/documents`: List uploaded documents and evidence metadata.
- `GET /api/documents/{document_id}`: Retrieve document details, sections, and suggested questions.

### General Topic Research
- `POST /api/research`: Conduct external web research for general topics without uploading files. Deduplicates sources, chunks, embeds, and indexes in Qdrant.

### Multi-Agent Debate
- `POST /api/debates`: Initialize a new multi-agent debate session with configured rounds. Dispatches LangGraph state machine.
- `POST /api/debates/{debate_id}/start`: Start or resume an existing debate session.
- `GET /api/debates`: List debate history.
- `GET /api/debates/{debate_id}`: Retrieve debate session, rounds, turns, and synthesis.
- `GET /api/debates/{debate_id}/status`: Polling endpoint returning debate status (`idle`, `debating`, `completed`, `failed`).
- `GET /api/debates/{debate_id}/messages`: Ordered list of all debate turns with speaker roles and evidence citations.
- `GET /api/debates/{debate_id}/result`: Final Pydantic-validated judge evaluation report.
- `GET /api/debates/{debate_id}/synthesis`: High-level debate synthesis.
